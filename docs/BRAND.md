# ブランドガイド — Tsumugi (紡)

## 1. プロダクト名

| 形式 | 表記 |
|---|---|
| 英字 (推奨) | **Tsumugi** |
| 漢字 (装飾用) | **紡** |
| 読み | ツムギ (tsoo-MOO-gee) |
| 運営会社 | 株式会社グロウリンク (Growlink Inc.) |

## 2. 由来

「紡ぐ」= 糸を撚り合わせて一本にすること。
医療・福祉という対人業界で、AI が **求職者の事情** と **施設の現場** を 1 本の糸に紡ぐ、というメタファー。
本ソフトの価値そのものを名前に込めた。

## 3. タグライン

| 言語 | タグライン |
|---|---|
| 日本語 | AI が、人と現場を丁寧に紡ぐ。 |
| English | Weave people into the right place, with care. |

## 4. カラーパレット

| 役割 | HSL | 用途 |
|---|---|---|
| Primary (深紺) | `215 56% 24%` | ボタン主色、ロゴ背景、ナビ |
| Warning (山吹) | `35 92% 45%` | アクセント、ロゴ糸、警告 |
| Secondary (生成) | `38 35% 92%` | カード背景、控えめ強調 |
| Success (深い緑) | `152 55% 32%` | 完了バッジ |
| Background (生成 off-white) | `38 30% 98%` | ベース |
| Foreground (紺褐色) | `215 35% 14%` | 本文 |

ダーク版もすべて `src/app/globals.css` で定義済み。

## 5. ロゴ使用

- 単独ロゴ: `<TsumugiLogo />` — 角丸の藍ベース + 山吹 / 生成の糸
- ワードマーク併記: `<TsumugiLogo withWordmark />`
- 文字色は `currentColor` ベースなので、暗背景でも反転で利用可
- **禁止**: 比率変更 / 糸の色変更 / 単独で 24px 以下の表示

## 6. タイポグラフィ

- 本文フォント: Inter → Hiragino Sans → Noto Sans JP (フォールバック)
- 数字: `font-feature-settings: "palt"` で詰めを有効
- 見出しは `text-balance` を併用してジャパニーズ可読性を担保

## 9. UI ライティング指針

| 場面 | 文言例 |
|---|---|
| 完了 | 「保存しました」「ご提出ありがとうございます」 |
| エラー | 「再度お試しください」「担当者にご連絡ください」 (技術用語禁止) |
| 空状態 | 「まだ {X} はありません」「{次のアクション} から始めてください」 |
| 確認 | 「{動詞} します。よろしいですか?」 |

敬体 (です・ます) で統一。求職者向けは特に柔らかく、施設向けは事実ベースで簡潔に。
